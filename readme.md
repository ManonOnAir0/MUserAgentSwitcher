# 🚀 MUserAgentSwitcher

Bienvenue sur **MUserAgentSwitcher**, l'extension conçue par **ManonOnAir** pour reprendre le contrôle de votre navigation. 

Marre des restrictions arbitraires ou des bugs étranges sur certaines plateformes ? Cette extension vous permet de simuler un autre navigateur (User-Agent) en un seul clic, optimisant ainsi votre expérience, notamment sur Twitch.

## ✨ Pourquoi utiliser MUserAgentSwitcher ?

- **Fluidité sur Twitch** : Corrige les bugs de lecture et les limitations imposées par certains navigateurs.
- **Simplicité** : Une interface propre, moderne et intuitive.
- **Efficacité** : Changez votre identité de navigateur instantanément sans recharger manuellement ou fouiller dans les réglages complexes.
- **Liberté** : Naviguez sans limites, comme si vous étiez sur Chrome, peu importe votre navigateur actuel.

## 🛠️ Installation

L'extension est disponible sur le **[Chrome Web Store](https://chromewebstore.google.com/detail/museragentswitcher/hpidffhjmeaoahaibclmkgfhkpcgmnff?hl=fr)**.

## 📖 Comment ça marche ?

1. Cliquez sur l'icône de l'extension.
2. Choisissez le profil de navigateur que vous souhaitez simuler.
3. Profitez d'une navigation sans accroc.

## 🔒 Sécurité & Éthique

- **100% Local** : L'extension fonctionne entièrement sur votre ordinateur. Aucune donnée de navigation n'est collectée, transmise ou vendue. Votre vie privée reste privée.
- **Fonction native** : Le changement de User-Agent est une fonctionnalité native de tous les navigateurs modernes. Nous avons simplement créé une interface pour l'activer plus facilement, sans avoir à fouiller dans les menus techniques.
- **Responsabilité** : L'outil respecte les règles des sites web. En l'utilisant, vous vous engagez également à respecter les conditions d'utilisation des plateformes que vous visitez.
